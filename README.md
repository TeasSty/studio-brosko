# BROSKO — сайт-концепт

Индивидуальная концепция «От образца к комнате» для студии дизайна интерьера BROSKO (Архангельск).

## Запуск

```bash
cd web
npm install
npm run dev
```

## Стек

- Vite + React + TypeScript
- Bodoni Moda + Manrope
- Без UI-kit шаблонов

## Важно

Фотографии на макете — временные референсные кадры (Unsplash). Перед показом клиенту заменить на архив BROSKO из VK / съёмки.
